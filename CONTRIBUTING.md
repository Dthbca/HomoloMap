# Contributing

Bug reports, documentation fixes, and focused pull requests are welcome.

1. Open an issue describing the scientific or software problem.
2. Create a branch from `main`.
3. Add or update tests for behavioral changes.
4. Run `python -m pytest` and `python -m compileall -q src`.
5. Submit a pull request describing the atlas, data representation, and expected behavior.

Do not commit restricted datasets, participant-level information, access tokens, absolute server paths, or large generated outputs.
